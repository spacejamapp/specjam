# Intro

Handbook for [Spacejam](https://spacejam.app), see [Releases](https://github.com/spacejamapp/specjam/releases) for the latest binaries.

## Getting Started

```bash
curl -fsSL https://sh.spacejam.dev | sh
```

### macOS Installation

```bash
brew tap spacejamapp/spacejam
brew install spacejam
```
